# SE2001 System Commands OPPE syllabus

| **Week** | **Topics** | **Concepts Being Tested** |
|---------|------------|----------------------------|
| **1** | Basic commands, command syntax, file system, paths, navigation, system info, permissions, file operations, aliases, links | Navigate the VM filesystem to access question folders, view questions, and write solutions. |
| **2** | Command Line Editors (vim/emacs/nano) | Write solutions using any CLI editor, save files, and modify script permissions. |
| **3** | Combining Commands and Files – command chaining, subshells, redirection, file descriptors; Redirections – output/input, pipes, tee, /dev/null, error handling | Understand and apply command combinations and redirections in both solution and evaluation scripts. |
| **4** | Regex basics, special characters, anchors, quantifiers, backreferences, POSIX classes, advanced grep; cut, fold, paste, tr | Write BRE/ERE regex patterns; fold/merge lines; manipulate input streams for transformations. |
| **5** | Shell Variables – usage, default/substitute values, substring, length, pattern removal (greedy & non-greedy), case change | Declare, use, and manipulate shell variables effectively. |
| **6 & 7** | Shell Scripting – find, tar, gzip, compression tools, disk usage, file search; scripting fundamentals – shebang, variables, loops, conditionals, functions, execution methods; advanced scripting – arithmetic, regex, heredoc, string ops, IFS, debugging, getopts, control flow (break, continue, shift, exec, eval, select) | Create elaborate shell scripts with proper structure and control flow; perform arithmetic and argument parsing. |
| **8** | Stream Editor (sed) – line selection, deletion, search-replace, address ranges, regex, insert/append/change, join lines, script files, debugging | Create sed commands and multi-command sed scripts with conditional/unconditional operations. |
| **9** | AWK – records & fields, BEGIN/END, built-in vars (FS, NF, NR, etc.), pattern-action model, regex matching, arrays, loops, conditions, functions, formatting (printf, sprintf), getline, string ops (substr, match), big file processing, system integration | Create AWK commands and multi-block AWK scripts for real-world tasks with conditional logic and formatting. |

**Exam Format Notes:**
- OPPE will consist of **5 mandatory questions**, each with **equal weightage**.
- Questions will resemble **VM formats** like BPT, PPA, or practice questions.
- Equal emphasis is placed on **all weeks**.
- A **mock NPPE** will be released for practice and SSH debugging—make full use of it.
